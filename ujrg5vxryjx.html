Загрузка ZIP в GitHub

Архив режется на части по 8 MB и уходит в репозиторий через Git Data API: сначала blobs, потом один коммит. Обрыв связи безопасен — уже загруженные части пропускаются.


Токен хранится только в памяти страницы и отправляется исключительно на api.github.com. Он не пишется в адрес, в лог и на сторонние серверы.
